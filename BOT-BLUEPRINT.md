# BOT-BLUEPRINT: автоматизация всех найденных эджей (октябрь 2026)

> Пересмотр OPTIONS.md при условии «исполнение = бот, сложность не важна».
> Что меняется: открываются активные/эпизодические эджи (фандинг-дислокации, депег-триаж,
> ротация стеков), исчезает надбавка за простоту. Что НЕ меняется: ёмкости, хвосты,
> и тот факт, что часть решений остаётся за человеком.
> Дата: 21.10.2026. Не инвестиционная рекомендация.

## 0. Итог для бота

**Потолок при полной автоматизации: ~13–17% годовых** на долларовый капитал против 10–14% у ручного режима — прибавка возникает за счёт систематического сбора эпизодических окон (фандинг 6×/мес, ротация кампаний Merkl, PT-сигналы), которые человек пропускает. НО: бот сам становится фактором риска — каждый модуль обязан иметь позиционные лимиты и kill-switch (баг в боте = потеря быстрее любого рынка).

## 2. Архитектура (минимальный жизнеспособный бот)

```
┌─ СБОР (без ключей, только чтение) ─────────────────────────────┐
│ funding: Binance/Bybit/OKX fapi + HL info  (каждые 1–5 мин)     │
│ pegs: CoinGecko + биржевые bookTicker USDT/USDC (1 мин)         │
│ pools: DefiLlama /pools (1 час)                                 │
│ pendle: api-v2 /markets + yield-history (1 час)                 │
│ merkl: /v4/opportunities?status=LIVE (1 день)                   │
│ loops: RPC — health factor, ставки (5 мин)                      │
└──────────────────────────────────────────────────────────────────┘
┌─ МОЗГ (правила = из этого репозитория, без ML) ────────────────┐
│ dislocation_engine:  спрэд>4 п.п. на ≥2 снимках подряд          │
│ pendle_engine:        implied − trailing30 > +200 б.п.           │
│ pool_engine:          vol/TVL>20x на 7 дней подряд + fee-tier   │
│ stack_engine:         кампания жива? APR>альтернативы?           │
│ depeg_engine:         |peg|>50 б.п. ×3 источника + redemption-тест│
│ risk_governor:        лимиты/позиции/kill-switch/полный стоп     │
└──────────────────────────────────────────────────────────────────┘
┌─ ИСПОЛНЕНИЕ (ключи только здесь, лимитированные) ──────────────┐
│ CEX: createOrder (perp-perp legs) — API-ключи trade-only        │
│ On-chain: кошелёк с суточным ceiling, мультисиг на вывод        │
└──────────────────────────────────────────────────────────────────┘
```

**Ключевое правило:** ключи чтения и исполнения физически разные; on-chain кошелёк бота держит ≤ суточного операционного лимита; вывод — мультисиг человека.

## 3. Risk governor (главный модуль — важнее всех стратегий)

1. **Позиционные лимиты:** перп-перп ≤ 2x NAV на пару; PT ≤ 15% портфеля; LP ≤ 10%/пул; стеки ≤ 15%/стек; луп-нога ≤ 35% (сохраняем структуру APY-MAX).
2. **Kill-switch на каждое правило:** фандинг-окно закрывается при <1 п.п.; PT-позиция при сжатии спрэда <100 б.п. (продажа не нужна — hold до экспирации дешевле); LP при depeg 0.5% ИЛИ оборот <10x на 3 дня; луп при спрэде <1 п.п. или HF ниже порога.
3. **Сторож бота:** heartbeat; если модуль не отвечал N минут → все ордера на закрытие эпизодических позиций; исключение — стратегии, где бездействие безопаснее (PT/база).
4. **Полный стоп:** рычаг на исполнение снимается при просадке портфеля >X% за день (рекомендация 5%) — человек разбирается.
5. **Запрет-лист (из репо):** no exotic PT, no новых протоколов без флага «verified» в data/, no снайпинг, no ликвидации.

## 4. Что остаётся за человеком (не автоматизируется в 1-й версии)

- **Классификация депега:** бот может дать все факты (redemption жив? депег на одной площадке или везде? объём продаж?), но решение «технический vs фундаментальный» — за человеком: 3 из 9 депегов не вернулись, цена ошибки — весь год премии. Автопокупка разрешена только при одновременном выполнении жёстких прокси-правил (WS-19 §6).
- **Новые рынки/протоколы:** whitelist обновляет человек после прохода фильтров сканера.
- **Изменения режимов:** hike-циклы ФРС, смерти премий (Merkl-кампании кончаются не мгновенно) — ревизия параметров раз в месяц.

## 6. Честные потолки

- Автоматизация не создаёт эдж — она только собирает найденный. Сумма всех восьми модулей в идеальном исполнении: **~13–17%** при долларовом номинале; выше — только продажа хвостовой страховки (плечи >7x на хрупких спрэдах, кредитная концентрация), что для бота опаснее, чем для человека: он продаст хвост без колебаний.
- Конкуренция реагирует: фандинг-эпизоды живут часы — если бот не единственный, EV съедается. Наша статистика эпизодов (6/мес × ~8 ч) даёт фору медленным правилам с порогом «2 снимка подряд».
- Операционный риск реален: за 2025–2026 взломы инфраструктуры (Bitget $387M — signing-сервис) — исполнение бота проектировать как критическую инфраструктуру.
