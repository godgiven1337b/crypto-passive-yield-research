## 1. Платформа

### 1.1. Что такое Limitless (окт-2026)

- Предикшн-маркет на **Base (chainId 8453)**, коллатераль **нативный USDC** (`0x8335...2913`), оракул-резолюция Pyth/Chainlink/спорт-фиды. Контракты: канонический Gnosis CTF + CTF Exchange (CLOB) + NegRisk — **форк Polymarket** ([docs: smart-contracts, security]).
- Юридическое лицо — **Street Chow Inc., панамская компания** (ToS, обновлён 2026-09-15).
- Продукт полностью Polymarket-подобный: yes/no-токены ERC-1155, NegRisk-категории, CLOB GTC/FOK/FAK, merge/split, AMM-легаси, паки (парлеи), UGM (юзер-генерированные), эмбед-маркеты. В доках есть прямой гайд **«Migrate from Polymarket»**.
- Категории (548 активных рынков, 26 категорий, live-проба 24.10): крипто up/down **5-мин / 15-мин / часовые / дейли / викли** (ETH, BTC, SOL, XRP, BNB, DOGE), акции-дейли (SPY, AAPL, NVDA…), спорт (теннис, крикет), киберспорт (LoL Worlds и др.), политика, паки, UGM. Т.е. **не только up/down** — но крипто-серия — костяк автоматики (`automationType: lumy`).

### 1.2. Ключевая механика 5-мин рынков (подтверждено живыми пробами)

- Слоты предсоздаются: `/markets/timeline?symbol=ETH&frequency=minutely&subFrequency=minutes_5` возвращает anchor/current/next/batch. **Следующий слот листингуется и торгуем до закрытия текущего**.
- Slug-сетка предвычислима с 01.07.2026: `eth-up-or-down-5-min-<unix-sec кратно 300>` — **идентично Polymarket** (`eth-updown-5m-<тот же таймстемп>`); в метаданных рынка: `externalProvider: "polymarket"`, `externalSlug: "eth-updown-5m-1792825200"`, `isPolyArbitrage: true`. **Limitless 5-мин рынки — зеркало Polymarket-слотов**.
- Резолюция: **Chainlink 60s-TWAP** (`eth-usd-twap-60s-streams`, `streamType: "twap"`); Up если closing TWAP ≥ Price-to-Beat (TWAP на open). Точное «Price to Beat» вшито в описание: напр. $2375.7523… для слота 06:20–06:25 24.10. Миграция со спота на TWAP — **19.08.2026** (changelog).
- `shouldMarketMake: true` — платформа держит **собственный ММ** на этих рынках (объясняет единичные уровни в книге типа бида 0.927×5 шеров).
- `takerDelayMs: 250` (5-мин) / `500` (15-мин) — принудительная задержка тейкера: **анти-снайпинг против оракульного потока**. Плюс taker-fee 5%×(1−p) — двойной барьер для латенси-арба против Chainlink-стрима.
- Резолв быстрый: WS-событие `marketResolved` для слота 06:50–06:55 пришло в 06:57:03 — **лаг ~2 мин** после закрытия. `winningOutcomeIndex`: 0=YES, 1=NO.

### 1.4. TVL/кастодия

- Протокольной кастодии нет: «Limitless does not hold a platform balance» — USDC всегда в кошельке юзера на Base (EOA — полностью свой кошелёк; соц-логин — Privy embedded/smart wallet, gas спонсируется платформой). Трейды сеттлятся он-чейн через CTF Exchange.

## 2. Экономика

### 2.1. Комиссии (полная структура)

**Новые venue (все новые рынки с 14.10.2026; наш 5-мин — на них):**

| Параметр | Значение |
|---|---|
| Taker | `5% × (1 − price)` от USDC-нотионала, **в USDC, с обеих сторон**, через feeModule `0x7B6ffe5b...` (simple) / `0x01b7dF64...` (NegRisk) |
| Maker | **0** |
| Формула | `fee = rate_bps·N·(S−N)/(10000·S)`, N = USDC-нотионал матча, S = шеры; округление half-up до 10 raw (0.00001 USDC), минимума нет |
| Резерв на бай | 5% суммы ордера холдится как максимум фи (заполнение может быть лучше лимита) |
| Подпись | В EIP-712 ордере `feeRateBps = 0` (иначе `FEE_RATE_MISMATCH`); апрув USDC → feeModule обязателен для всех ордеров кроме postOnly |
| Профильные кэпы | `effectiveFeeRateBps` в профиле — индивидуальное снижение ставки |

Шкала: $0.01→4.95%, $0.10→4.50%, $0.25→3.75%, $0.50→2.50%, $0.75→1.25%, $0.90→0.50%, $0.99→0.05%.

**Легаси-venue (рынки до 14.10.2026):** taker buy 0.40–3.00% (платится outcome-токенами, максимум на дешёвых), taker sell 0.42–1.50% (USDC, пик на $0.50), maker 0; AMM — плоско 0.40%; UGM-кастомные — 2% в пул создателя.

**Экономический смысл для 5-мин:** на p≈0.50 тейкер платит 2.5% нотионаяла в круг; стратегия «купил YES @0.50 + продал @0.60» платит ~2.5%+1.25% ≈ 3.7¢ с доллара — на 10¢ движения съедает более трети. Тейкерская скальп-логика против внутреннего ММ почти мертва; **maker-модель — единственная безфиковая**.

### 2.2. Ребейты и LP-награды

- **Maker-ребейты**: дневной USDC-пул из доли taker-фий; `settings.rebateRate` на 5-мин/15-мин = **0.3** (30% собранных taker-фий → пул мейкеров), на Daily/Hourly Crypto исторически 100% (changelog 04.2026). Выплаты ежедневно, pro-rata по ребейт-кредиту от фактических филлов.
- **LP-награды**: за рестинг-лимиты в `maxSpread` от мида; на 5-мин `dailyReward = 0` — **LP-наград на 5-мин нет**; на 15-мин тоже 0. `maxSpread` (0.065 на 5-мин) — это зона наград, не ограничение ордера.
- **Points-программа** (`isRewardable: true` на 5-мин): сезоны с архивом season1/2/3+ и живым `currentSeason` (`GET /portfolio/points`) — трейдинг на rewardable-рынках капает поинты (эйрдроп-механика; UGM-трейдинг исключён с 09.2026).

## 3. API для бота

### 3.1. Общее

REST `https://api.limitless.exchange` (единый глобальный эндпоинт), WS `wss://ws.limitless.exchange` (Socket.IO, namespace `/markets`). OpenAPI: `/api-json` + docs.limitless.exchange/openapi.json. **Тестнета нет** — репетиция только микрорядами на проде.

### 3.2. Авторизация

- Скоупные API-токены из UI (profile → API keys): `tokenId` + `secret` (показывается один раз). HMAC-SHA256 на каждый запрос: заголовки `lmts-api-key`, `lmts-timestamp`, `lmts-signature`.
- Скоупы: `trading`, `account_creation`, `delegated_signing`. Легаси `X-API-Key` депрекейтед. Для API-ордеров профиль должен быть в **EOA trading mode** (если включал 1-click smart wallet в аппке — переключить одним authenticated-вызовом).
- Партнёрский доступ (субаккаунты, delegated signing, packs) — по заявке.

### 3.3. Исполнение

- EIP-712 подпись ордера с `verifyingContract` = venue exchange (наш — `0x05c748E2...`); `POST /orders` c `ownerId`, `orderType` (GTC/FOK/FAK), `marketSlug`, tokenId yes/no.
- Богатый набор: cancel-replace (+batch), batch-cancel, cancel-all, `clientOrderId` идемпотентность, `recvWindow` (425 на устаревший ордер), `GET /orders/status/batch`.
- **Market Maker Heartbeat** (`POST /heartbeats`): дедлайн-таймер — если сервис молчит, Limitless сам отменяет все ваши ордера. Прямо задумано под ММ-ботов.
- `takerDelayMs: 250` на 5-мин — закладывать в модель исполнения.

### 3.4. Rate limits (из changelog)

- **5 мутаций/мин на профиль** (ордера+канселы!) — главный ограничитель для активного бота; для расширения — письменно help@limitless.network.
- 120 публичных чтений/мин на IP; 60 приватных чтений/мин на аккаунт; партнёрские pack-маршруты 10 req/10s. 429 c `Retry-After`, SDK имеют OrderQueue/ретраи.

### 3.5. WebSocket (проверен живьём)

- Публичные каналы **без авторизации**: `subscribe_market_prices` (orderbookUpdate/newPriceData), `subscribe_market_lifecycle` (marketCreated/Updated/Resolved — принял два резолва 5-мин слотов в реальном времени), `subscribe_oracle_price_data` (стрим оракульных цен!), `subscribe_unrealized_pnl`.
- Приватные (позиции, order events, tx) — HMAC-hendшейк, сабскрайбы в течение 30с от хендшейка; коннект живёт 24ч (потом 1006, пересоединение с переподписью).
- Нюанс: unsubcribe почти нет — повторный subscribe заменяет набор.

### 3.6. SDK и прочее

TS `@limitless-exchange/sdk`, Python `limitless-sdk`, Go, Rust (≥1.2.0 детектят новый venue и подписывают feeRateBps=0). Дополнительно: MCP-сервер доков (`docs.limitless.exchange/mcp`) и **торговый MCP** (`api.limitless.exchange/mcp`) для агентов; гайд Build a Trading Agent; официальный пример стратегии **cross-market MM (квотируй Limitless / хеджируй Polymarket)** — platформа сама описывает эту экономику: maker без фии + ребейты + LP против Polymarket-taker-фии.

**Оценка готовности API: 9/10.** Всё для бота есть (идемпотентность, heartbeat, батчи, WS-оракл, таймлайн слотов, SDK). Минусы: 5 мутаций/мин, нет тестнета, 24ч-обрыв WS, регистрозависимые адреса в public-portfolio.

## 5. Доступ

- **Гео (ToS 15.09.2026):** для трейдинга закрыты **США, Китай (ROC), Онтарио, Альберта**; полностью закрыты РФ, Беларусь, Куба, Иран, КНДР, Сирия, Крым/Донецк/Луганск. Остальное — «void where prohibited», ответственность на юзере. Технического геофенса в API не наблюдалось (проверено анонимным доступом), но ToS даю право моментальной блокировки и конфискации.
- **KYC:** обязательного нет; компания «вправе запросить» доказательства в любой момент.
- **On-ramp:** только USDC на Base в свой кошелёк (бридж сам); соц-логин (Google/Twitter/email) → Privy embedded/smart wallet, gas спонсируется. Карт/банковских рамп в доках нет.

## 8. Выводы для стратегии

1. **API-инфраструктура — сильнейшая сторона**: бот собирается за дни (SDK, timeline, WS-оракл, heartbeat, идемпотентность). Для 5-мин серии есть всё, включая предвычислимые слуги и Price-to-Beat в описании рынка.
2. **Но альфа-поверхность пуста**: $337 за 6 часов на всю серию. Taker-путь заблокирован экономикой (fee 2.5% на п.50 + takerDelayMs 250мс). Maker-путь — 0 фий, но филлы возможны в основном против внутреннего ММ, который котирует по Polymarket: вы стабильно платите/получаете парити-цену, ребейт-пул 30% от почти нулевых фий.
3. **Краеугольный камень**: Limitless — не источник цены, а **зеркало Polymarket** (`isPolyArbitrage: true`). Кросс-венue эдж = разница Liquid–PM исполнение+фии; PM-хедж (taker ~0.05–0.07·p(1−p)) против Limitless-maker-0 делает официальный cross-MM сценарий осмысленным только при реальном флоу на Limitless.
4. **Мониторинг-триггер**: если суточный объём 5-мин серии вырастет с ~$1.4K до $10K+ (например, после листинга наград/points на 5-мин) — пересмотреть приоритет; сегодня это академический интерес.
5. **Риски исполнения малой площадки** (панамский офшор, unaудited diffs, короткая история) — держать экспозицию минимальной; US-блок значит и юрисдикционную чувствительность всей затеи.
